# My Dotfiles (managed with yadm)

These are my personal dotfiles, managed using [yadm](https://yadm.io/).

## 🚀 Quick Start

1. **Install yadm**  
   - macOS: `brew install yadm`  
   - Debian/Ubuntu: `sudo apt install yadm`  
   - Arch Linux: `sudo pacman -S yadm`  
   - [See more installation options](https://yadm.io/docs/install)

2. **Clone this repo with yadm**  

   ```bash
   yadm clone git@github.com:edrenck/dotfiles.git
   ```

   This will set up your home directory with these dotfiles.
